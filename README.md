# STRC Research

This repository publishes computational work on STRC-related DFNB16 hearing loss, from variant evidence to gene-therapy hypotheses, so specialists can check it and challenge it.

## About

This is the source for [strc.egor.lol](https://strc.egor.lol). The site keeps the evidence, methods, models, hypotheses, and known limits of the project in one public record.

The work is computational research. Laboratory and clinical experts must review each result before anyone treats it as biological or medical evidence.

## Development

Requires Node.js 22.12 or newer.

```sh
npm install
npm run dev
npm run build
```

Astro writes the production build to `dist/`.
